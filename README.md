# КАССА — TUMAR HOSTEL

Версия 2.0.0. Простая офлайн-касса без товаров.

## Реализовано
- фиксированная смена 10:00 → 10:00 следующего дня;
- ввод суммы и быстрые суммы;
- наличные / банк;
- выбор даты и времени продажи;
- обязательная кнопка подтверждения продажи;
- история операций;
- удаление ошибочно добавленных операций;
- просмотр электронного чека без печати;
- итог смены: количество, общая сумма, наличные, банк;
- полный PDF-отчёт за текущую смену со всеми транзакциями;
- возможность поделиться PDF;
- полностью офлайн, SQLite на телефоне;
- без раздела товаров.

## Сборка APK через GitHub Actions
Workflow: `.github/workflows/build-apk.yml`.
